Set up a shortcut on your iPhone

Do this once per command. About 2 minutes each.

  1. Open Shortcuts → tap +. Name it what you'll say, e.g. Add to house.
  2. Add the action Dictate Text.
  3. Add Get Contents of URL. Set the URL to one of the links below, tap Show More, and set:
    • Method: POST
    • Headers → Add: Authorization = Bearer + a space + your key
    • Request Body: JSON → Add field: text (Text) = Dictated Text
  4. Add Speak Text and set it to Contents of URL, so Siri reads out the result.
  5. Say “Hey Siri, Add to house”, then say the item.
